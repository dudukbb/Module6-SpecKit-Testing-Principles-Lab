# Mutation Testing Reports

This folder stores mutation testing outputs for Module6.

## Expected Outputs
- `mutation-report.json`: Machine-readable mutation report generated by Stryker.
- `html/`: Human-readable HTML report generated by Stryker.
- `mutation-summary.md`: Curated summary of survived mutants and test hardening actions.

## Execution
Run from `Module6/backend`:

```bash
npm run test:mutation
```

## Target Gates
- Mutation score: >= 75%
- Coverage baseline: >= 80% lines, >= 75% branches

These thresholds align with constitution testing principles.
